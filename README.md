# GABIGABI

画像をJPEGで繰り返し再保存して、ガビガビにするブラウザアプリ。

公開先: https://sino-s.github.io/gabigabi/

画像選択またはドロップ → 品質と回数を設定 → 「ガビガビにする」 → JPEGを保存。
サンプル画像でも試せます。画像の処理はブラウザ内で完結し、アップロードされません。

## 仕組み

CanvasからJPEGを生成し、そのJPEGをデコードして次の保存に使用します。
前の世代を実際に再圧縮する処理で、単に初期画像を何度も書き出す処理ではありません。
同じ品質でのJPEG再保存は数世代で変化が小さくなるため、標準では品質を最大6ポイントずつ変動させます。
チェックを外すと指定の品質だけで再保存します。JPEGエンコーダーはブラウザにより異なります。

透過部分は白に変換されます。長辺は設定したサイズ以下に縮小されます（拡大なし・上限4000px）。
アニメーション画像は静止画として扱います。入力ファイルの上限は40MiBです。
大きな画像や多い回数では処理に時間がかかります。途中で中止できます。

## ローカルで実行

ビルドや依存ライブラリは不要です。

```sh
python3 -m http.server 8080
```

http://localhost:8080 を開いてください。

## GitHub Pages

公開リポジトリの Settings → Pages で「Deploy from a branch」、`main` の `/(root)` を選びます。
HTML/CSS/JavaScriptだけの静的サイトなので、ビルドは不要です。
